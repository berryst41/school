# 📌 저장 정리 비서

인스타그램에 저장해 둔 릴스·피드를 **여러 개 골라서 AI가 읽고** 맛집·레시피·여행·쇼핑으로 보기 좋게 정리해 줘요.

주소: https://berryst41.github.io/school/insta/

## 쓰는 방법
1. **처음 한 번:** 폰 크롬으로 위 주소를 열고 ⋮ → "홈 화면에 추가(설치)". ⚙️ 설정에서 무료 AI 키를 넣어요. (aistudio.google.com/apikey 에서 구글 로그인 후 "Create API key")
2. **저장하기:** 인스타 게시물에서 **공유 → 저장 정리 비서**를 누르면 링크가 들어와요. 캡션을 길게 눌러 복사해 붙여넣고, 릴스는 화면 녹화(말소리·자막까지 읽어요)나 스크린샷을 올려요.
3. **정리하기:** 목록에서 여러 개 체크 → **🤖 AI 정리**. 카드마다 제목·요약·가격·위치(네이버·구글 지도 링크)·조리 순서가 나와요.
4. **묶어서 보기:** 정리된 것 2개 이상 체크 → **🧺 묶어서**. 맛집은 지역별, 레시피는 장보기 목록, 여행은 코스, 쇼핑은 비교표로 묶어 줘요.

## 알아 두기
- 인스타 링크만으로는 영상·캡션을 가져올 수 없어요(인스타가 막아 둠). 그래서 캡션 붙여넣기 / 화면 녹화를 써요.
- 영상·사진은 합쳐서 14MB까지. 모든 글·사진은 **이 폰 안에만** 저장되고, AI 키도 폰 안에만 있어요. (AI 정리할 때만 구글 Gemini로 보내져요.)
- ⚙️ 설정의 "백업 받기"로 글과 정리 결과를 파일로 저장해 둘 수 있어요(원본 영상·사진은 제외).
- 업데이트: 코드를 고쳐 올리면 앱을 다시 설치하지 않아도 다음에 열 때 바뀌어요.
