# 💑 우리 둘

**둘만 쓰는 커플 앱이에요.** 휴대폰에서 주소를 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

### [💑 우리 둘 열기](https://berryst41.github.io/school/couple/)

## 할 수 있는 것

| 메뉴 | 하는 일 |
|:---|:---|
| 🏠 홈 | 사귄 날부터 **D-day**, 다가오는 기념일(100일 단위, 주년, 생일 같은 날) |
| 🔔 기념일 알림 | 기념일이 7일 안으로 다가오면 홈에 알려 줘요. **휴대폰 달력에 알림 넣기**를 누르면 하루 전 저녁 8시, 당일 아침 9시에 휴대폰이 알려 줘요 |
| 📅 일기 | 달력에서 날짜를 눌러 그날 있었던 일을 적어요. 사진도 붙이고, **둘 다 고칠 수 있어요** |
| 🖼️ 앨범 | 사진을 함께 올리고 봐요 |
| 🗺️ 지도 | **세계**는 나라별, **국내**는 시·도별로 여행 기록을 남겨요. 대표 사진이 그 나라(지역) 모양으로 지도에 채워져요 |
| ✅ 버킷 | 함께 하고 싶은 것을 적고, 해내면 체크하고 인증 사진을 남겨요 |
| 🎬 문화 | 영화·드라마·책·전시·공연·방탈출 등을 별점, 날짜, 사진, 메모와 함께 기록해요 |

## 처음 쓰는 법

1. 주소를 열고 **처음이에요 (계정 만들기)** 를 눌러요.
2. 받은 **초대 코드**, 별명, 아이디, 비밀번호를 적어요. 계정은 **두 개까지만** 만들어져요.
3. ⚙️ 설정에서 **사귄 날**을 넣으면 D-day가 나와요.
4. 홈 화면에 두기
   - 아이폰: 사파리 아래 공유 단추 → **홈 화면에 추가**
   - 갤럭시: 크롬 오른쪽 위 ⋮ → **홈 화면에 추가**

> [!NOTE]
> 기록과 사진은 자료 공유 사이트와 같은 Supabase에 따로 저장되고, 로그인한 두 사람만 볼 수 있어요.
> 사진은 올릴 때 휴대폰에서 알맞은 크기로 줄여서 저장 공간을 아껴요.
