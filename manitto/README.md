# 🎁 마니또 뽑기

**우리반 아이들이 한 명씩 나와서 버튼을 누르면 자기 마니또를 뽑아요.**
설치 없이 링크만 열면 되고, 아이들 이름은 선생님 컴퓨터 밖으로 나가지 않아요.

### [🎁 마니또 뽑기 열기](https://berryst41.github.io/school/manitto/)

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

## 이런 점을 꼭 지켜요

- 자기 자신을 뽑는 일이 **없어요.**
- 한 친구가 두 번 뽑히거나, 아무도 안 챙겨 주는 친구가 남는 일이 **없어요.**
- 두 친구가 **서로의** 마니또가 되는 일이 없어요. (A가 B를 챙기면, B는 A가 아닌 다른 친구를 챙겨요)
- 마지막 아이까지 위 조건이 지켜져요. 시작할 때 모든 짝을 한꺼번에 정해 두고, 아이들은 차례대로 확인만 하기 때문이에요.

> [!NOTE]
> 아이들을 무작위로 둥글게 세운 뒤 각자 옆 친구의 마니또가 되게 해요.
> 17만 번 돌려 시험했을 때 조건을 어긴 경우는 한 번도 없었어요.

## 사용법

| 순서 | 할 일 |
|:---:|:---|
| 1 | **[📂 엑셀 명렬표 불러오기]** 로 명렬표 파일을 고르거나, 이름을 **번호 순서대로 한 줄에 한 명씩** 넣고 **[마니또 뽑기 시작하기]** |
| 2 | 화면에 나온 번호의 아이가 나와서 **[뽑기!]** → 이름이 돌다가 멈춰요 |
| 3 | 확인한 뒤 **[확인했어요 (화면 가리기)]** → **[다음 친구 차례]** |
| 4 | 다 끝나면 **[전체 결과 보기 (선생님용)]** 에서 한눈에 보고, 엑셀·메모장 파일로 받거나 인쇄해요 |

> [!TIP]
> 진행 중에 창을 닫거나 새로고침해도 같은 컴퓨터·같은 브라우저라면 뽑던 곳부터 이어져요.
> **[처음부터 다시]** 를 누르면 결과가 지워지니 다 끝난 뒤에는 누르지 마세요.

## 엑셀 명렬표 불러오기

- 나이스 등에서 받은 명렬표 엑셀 파일(.xlsx, .xls, .csv)을 그대로 넣으면 돼요. 파일을 이름 칸에 끌어다 놓아도 돼요.
- 첫 번째 시트에서 **이름(성명)** 칸을 찾아 읽고, **번호** 칸이 있으면 번호 순서대로 정리해요. 위쪽의 학교 이름 같은 제목 줄은 건너뛰어요.
- 불러온 뒤 아래 명단과 순서가 맞는지 꼭 한 번 확인해 주세요. 이름은 선생님 컴퓨터 안에서만 읽고 어디로도 보내지 않아요.
