# 🤖 쿨메신저 비서

**쿨메신저로 받은 쪽지를 AI(제미나이)가 읽고, ✅ 마감 할 일 · 📅 일정 · 💡 알아 둘 것으로 나눠서 화면 구석의 작은 창에 정리해 주는 윈도우 프로그램이에요.**
새 쪽지가 오면 저절로 정리되고, 기한이 지난 건 알아서 사라져요.

### [⬇️ cool-ai.zip 내려받기 (v0.2.8)](https://github.com/berryst41/school/raw/main/cool-ai/cool-ai.zip)

지금 버전: **v0.2.8** (2026-11-23) · 바뀐 점은 [아래 버전 기록](#버전-기록)에 있어요.

## 설치하는 방법

| 순서 | 할 일 |
|:---:|:---|
| 0️⃣ | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 구글 계정으로 **제미나이 API 키**를 무료로 받아 복사해 둬요 |
| 1️⃣ | 압축 파일을 마우스 오른쪽 클릭 → **모두 압축 풀기** |
| 2️⃣ | 풀린 폴더에서 **1_설치하기.bat** 을 더블클릭해요 |
| 3️⃣ | 파란 **Windows의 PC 보호** 창이 뜨면 **추가 정보** → **실행** |
| 4️⃣ | API 키를 붙여 넣고 엔터, 내 정보(예: `5학년 담임`)를 적고 엔터 |
| 5️⃣ | 화면 오른쪽 아래에 **쿨메신저 비서** 창이 떠요. 처음에는 최근 7일 쪽지와 즐겨찾기(★) 쪽지를 정리하느라 몇 분 걸려요 |

컴퓨터를 켤 때마다 저절로 켜지고, 바탕화면의 **쿨메신저 비서** 아이콘으로도 켤 수 있어요.

## 쓰는 법

| 단추·키 | 하는 일 |
|:---:|:---|
| **F9** | 창을 맨 위로 올려요. 한 번 더 누르면 다른 창 뒤로 보내요 |
| 알림 영역 ☑ 아이콘 | 작업 표시줄 오른쪽 **^** 안의 파란 체크 아이콘. 누르면 창이 맨 위로 올라와요. 오른쪽 클릭하면 메뉴가 나와요. 아이콘을 ^ 밖 작업 표시줄로 끌어다 두면 늘 보여요 |
| 📌 | 맨 위 고정 켜기·끄기 (끄면 다른 창이 위로 올라올 수 있어요) |
| ◐ 막대 | 투명도 (창 위에서 **Ctrl + 마우스 휠**로도 돼요) |
| ⟳ | 지금 바로 쪽지 확인 |
| — | 창 숨기기 (작업 표시줄에는 안 떠요. **F9** 나 바탕화면 **쿨메신저 비서** 아이콘으로 다시 불러와요) |
| ⚙ | 설정 열기 (API 키, 단축키, 내 정보) |
| 체크 상자 | 다 한 일 표시 — 아래 **다 한 것 보기**에서 되돌릴 수 있어요 |
| 항목 두 번 클릭 | 원래 쪽지 보기 |
| ➕ | **직접 넣기** — 쪽지가 없어도 할 일·일정·알아 둘 것을 넣어요(Enter로 넣기). 직접 넣은 항목은 오른쪽 클릭으로 지워요 |

- 마감이 **오늘이면 빨간색**, 2일 안이면 주황색으로 보여요.
- 새 할 일이 생기면 노란색으로 표시되고, 창이 잠깐 맨 앞으로 나와요.
- 다른 학년·업무 쪽지를 빼고 싶으면 ⚙ 설정의 `내_정보`에 "5학년 담임"처럼 적어요.
- 단축키는 ⚙ 설정의 `단축키`에서 바꿔요 (예: `F8`, `Ctrl+F9`). 바꾼 뒤 창을 껐다 켜요.

## 어떻게 작동하나요?

- 쿨메신저는 받은 쪽지를 PC 안(`%LOCALAPPDATA%\CoolMessenger\Memo`)에 저장해요. 비서는 이 파일을 **복사본으로만 읽어서** 쿨메신저에는 아무 영향이 없어요.
- 새 쪽지만 골라 12통씩 제미나이에게 보내 정리해요. 무료 사용량을 넘지 않게 천천히 보내요.
- 쿨메신저에서 **즐겨찾기(★)한 쪽지는 오래된 것이어도** 읽어요. 나중에 즐겨찾기한 쪽지도 저절로 정리돼요.
- 기본 모델은 **gemini-flash-lite-latest** 예요. 더 똑똑한 `gemini-flash-latest`는 무료로 하루 20번뿐이고 느려서 추천하지 않아요.
- 🧰 따로 설치할 프로그램 없이 윈도우에 들어 있는 기능(PowerShell)만 써요.

> [!WARNING]
> **개인정보:** 쪽지 내용이 구글 제미나이로 보내져요. **무료** 제미나이는 보낸 내용을 서비스 개선(학습)에 쓸 수 있어요.
> 학생 개인정보가 많은 쪽지가 걱정되면 유료 키를 쓰거나, 설정의 `제외할_보낸사람`에 넣어 주세요.
> 정리한 목록과 API 키는 내 PC에만 저장돼요.

그만 쓰려면 **2_제거하기.bat** 을 더블클릭해요. (쿨메신저 쪽지는 그대로 남아요)
