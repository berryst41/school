쿨메신저 비서 사용방법
====================

■ 무엇을 하나요?
  쿨메신저로 받은 쪽지를 제미나이(AI)가 읽고 세 가지로 정리해서 작은 창에 보여 줘요.
   ✅ 해야 할 일   - 제출·회신·신청처럼 내가 해야 하는 일 (마감 순)
   📝 적어야 할 것 - 회의·행사·연수 같은 일정, 장소, 시간
   💡 기억할 것    - 알아 두어야 할 안내·바뀐 규칙
  새 쪽지가 오면 1분 안에 저절로 정리돼요.
  처음 켤 때는 최근 7일 쪽지 중 기한이 아직 안 지난 것만 정리해요.
  쿨메신저에서 즐겨찾기(★)한 쪽지는 기간과 상관없이 읽어요.
  기한이 지난 항목은 다음 날 저절로 사라져요.

■ 설치
  1_설치하기.bat 더블클릭 → 제미나이 API 키 붙여 넣기 → 끝
  API 키 받기: https://aistudio.google.com/apikey (구글 계정으로 무료)

■ 창 쓰는 법
  F9           창을 맨 위로 올리기 / 한 번 더 누르면 다른 창 뒤로 보내기
  ☑ 아이콘     작업 표시줄 오른쪽 ^ 안의 파란 체크 아이콘: 누르면 맨 위로, 오른쪽 클릭은 메뉴
               (^ 밖으로 끌어다 두면 늘 보여요)
  📌           맨 위 고정 켜기·끄기 (끄면 다른 창이 위로 올라올 수 있어요)
  ◐ 막대       투명도 (창 위에서 Ctrl + 마우스 휠로도 돼요)
  ⟳            지금 바로 쪽지 확인
  —            창 숨기기 (작업 표시줄엔 안 떠요. F9 나 바탕화면 아이콘으로 다시 불러와요)
  ⚙            설정 열기 (메모장)
  체크 상자     다 한 일 표시 (아래 "다 한 것 보기"에서 되돌릴 수 있어요)
  항목 두 번 클릭  원래 쪽지 보기
  제목 줄 끌기   창 옮기기,  오른쪽 아래 모서리 끌기: 크기 바꾸기

■ 설정 (⚙ 를 누르면 메모장으로 열려요)
  API키            제미나이 API 키
  내_정보          "5학년 담임"처럼 적으면 다른 학년 쪽지는 빼고 정리해요
  단축키           F9 대신 F8, Ctrl+F9 등으로 바꿀 수 있어요 (창을 다시 켜야 바뀌어요)
  처음_살펴볼_날짜  처음 켤 때 며칠 전 쪽지부터 볼지
  제외할_보낸사람   정리하지 않을 보낸 사람 (기본: 쿨서비스 일정 알림)

■ 꼭 알아 두세요 (개인정보)
  쪽지 내용이 구글 제미나이로 보내져요. 무료 제미나이는 보낸 내용을 서비스 개선(학습)에
  쓸 수 있어요. 학생 개인정보가 많은 쪽지가 걱정되면 유료 키를 쓰거나 제외할_보낸사람에 넣어 주세요.
  정리한 목록은 이 PC(%LOCALAPPDATA%\CoolAI)에만 저장돼요.

■ 그만 쓰기
  2_제거하기.bat 더블클릭 (쿨메신저 쪽지는 그대로 남아요)
