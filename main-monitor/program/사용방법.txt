[ 한글·엑셀을 항상 메인 모니터에서 열기 ]

이 프로그램을 설치하면, 한글이나 엑셀 파일을 열 때
창이 다른 모니터(전자칠판)에서 열려도 1초 안에 메인 모니터로 옮겨져요.
쓰는 도중에는 전자칠판으로 마음대로 옮겨도 괜찮아요.
껐다가 다시 열면 다시 메인 모니터에서 열려요.

------------------------------------------------------------
■ 0단계. 메인 모니터가 노트북으로 되어 있는지 확인 (처음 한 번만)
------------------------------------------------------------
 1) 바탕화면 빈 곳에서 마우스 오른쪽 클릭 → [디스플레이 설정]
 2) 위쪽에 1, 2 네모가 보이면 [확인]을 눌러 어느 화면이 몇 번인지 봐요.
 3) 노트북 화면 네모를 클릭하고, 아래로 내려서
    [이 디스플레이를 주 모니터로 만들기]에 체크해요.
    (이미 체크되어 있거나 회색이면 그대로 두면 돼요.)

------------------------------------------------------------
■ 1단계. 설치하기
------------------------------------------------------------
 1) 받은 압축파일(main-monitor.zip)을 마우스 오른쪽 클릭
    → [모두 압축 풀기]
 2) 풀린 폴더 안의 [1_설치하기.bat]을 더블클릭해요.
 3) 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.
 4) "프로그램 고르기" 창이 뜨면, 메인 모니터에서 열리게 할 프로그램에
    체크하고 [확인]을 눌러요.
    ★ 한쇼와 파워포인트는 체크를 끄는 걸 추천해요.
      (발표 화면은 전자칠판에 띄우는 경우가 많아서요)
 5) "설치가 끝났어요!"가 나오면 엔터 키를 눌러 닫아요.

 끝! 이제 고른 프로그램으로 파일을 열어 보세요.

 ※ 화면에는 보이지 않고 뒤에서 조용히 작동해요.
    컴퓨터를 켤 때마다 저절로 다시 켜져요.
 ※ 압축 푼 폴더는 나중에 프로그램을 다시 고를 때 쓰니 남겨 두면 편해요.

------------------------------------------------------------
■ 그만 쓰고 싶을 때
------------------------------------------------------------
 [2_제거하기.bat]을 더블클릭해요.

------------------------------------------------------------
■ 적용할 프로그램을 바꾸고 싶을 때
------------------------------------------------------------
 [3_프로그램고르기.bat]을 더블클릭해요.
 → 체크를 바꾸고 [확인]을 누르면 몇 초 안에 바로 적용돼요.
 (압축 푼 폴더를 지웠다면, 압축 파일을 다시 풀어서 실행하면 돼요.)

 고를 수 있는 프로그램:
 한글(한글 뷰어 포함), 한셀, 한쇼, 엑셀, 워드, 파워포인트, 아크로뱃(PDF)

------------------------------------------------------------
■ 알아두면 좋은 단축키
------------------------------------------------------------
 창을 클릭한 뒤  [윈도우 키] + [Shift] + [← 또는 →]
 → 지금 창이 옆 모니터로 바로 넘어가요. (전자칠판에 띄울 때 편해요)

------------------------------------------------------------
■ 잘 안 될 때
------------------------------------------------------------
 - 설치 창에 빨간 글씨가 나오면, 그 내용을 사진 찍어 보여 주세요.
 - 학교 컴퓨터는 보안 프로그램 때문에 막힐 수 있어요.
   이때는 정보 담당 선생님께 "PowerShell 스크립트 실행 허용"을 부탁해 보세요.
