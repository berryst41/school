[ 메인 모니터로 열기  v1.2.0 ]

이 프로그램을 설치하면, 한글·엑셀 같은 문서나 크롬·엣지·브레이브 같은
웹 브라우저를 열 때, 프로그램마다 골라 둔 모니터(메인 / 서브)에서 열려요.
 - 메인 모니터: 노트북 화면
 - 서브 모니터: 전자칠판처럼 옆에 연결한 화면
쓰는 도중에는 다른 모니터로 마음대로 옮겨도 괜찮아요.
껐다가 다시 열면 다시 골라 둔 모니터에서 열려요.

------------------------------------------------------------
■ 0단계. 노트북이 메인 모니터로 되어 있는지 확인 (처음 한 번만)
------------------------------------------------------------
 1) 바탕화면 빈 곳에서 마우스 오른쪽 클릭 → [디스플레이 설정]
 2) 위쪽에 1, 2 네모가 보이면 [확인]을 눌러 어느 화면이 몇 번인지 봐요.
 3) 노트북 화면 네모를 클릭하고, 아래로 내려서
    [이 디스플레이를 주 모니터로 만들기]에 체크해요.
    (이미 체크되어 있거나 회색이면 그대로 두면 돼요.)

------------------------------------------------------------
■ 1단계. 설치하기
------------------------------------------------------------
 1) 받은 압축파일(main-monitor.zip)을 마우스 오른쪽 클릭
    → [모두 압축 풀기]
 2) 풀린 폴더 안의 [1_설치하기.bat]을 더블클릭해요.
 3) 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.
 4) "열릴 위치 고르기" 창이 뜨면, 프로그램마다
    [메인 모니터] / [서브 모니터] / [사용 안 함] 중 하나를 고르고 [확인]을 눌러요.
    ★ 한쇼와 파워포인트는 처음에 "사용 안 함"으로 되어 있어요. 그대로 두는 걸 추천해요.
      (발표 화면은 서브 모니터에 띄우는 경우가 많아서요)
    ★ 브라우저(크롬·엣지·브레이브)도 처음에는 "사용 안 함"이에요. 원하면 골라 주세요.
 5) "설치가 끝났어요!"가 나오면 엔터 키를 눌러 닫아요.

 끝! 이제 고른 프로그램을 열어 보세요.

 ※ 화면에는 보이지 않고 뒤에서 조용히 작동해요.
    컴퓨터를 켤 때마다 저절로 다시 켜져요.
 ※ 압축 푼 폴더는 나중에 다시 고를 때 쓰니 남겨 두면 편해요.

------------------------------------------------------------
■ 열릴 위치를 바꾸고 싶을 때
------------------------------------------------------------
 [3_프로그램고르기.bat]을 더블클릭해요.
 → 고른 것을 바꾸고 [확인]을 누르면 몇 초 안에 바로 적용돼요.
 (압축 푼 폴더를 지웠다면, 압축 파일을 다시 풀어서 실행하면 돼요.)

 고를 수 있는 프로그램:
 문서     - 한글(한글 뷰어 포함), 한셀, 한쇼, 엑셀, 워드, 파워포인트, 아크로뱃(PDF)
 브라우저 - 크롬, 엣지, 브레이브

------------------------------------------------------------
■ 알아두면 좋아요
------------------------------------------------------------
 - 엑셀과 한글은 다른 모니터에 잠깐 떴다가 옮겨지는 일 없이, 처음부터 고른 모니터에서 열려요.
   (한글은 설치하고 처음 한두 번은 메인 모니터 왼쪽 위 근처에 열릴 수 있어요.
    고른 모니터에서 한 번 닫으면 그 자리를 배워서, 다음부터는 그 자리에 열려요.)
 - 다른 프로그램은 다른 모니터에서 닫았다면, 다음에 열 때 그쪽에 아주 잠깐 보였다가 옮겨져요.
 - 브라우저는 처음 켤 때의 창만 옮겨요. 탭을 끌어내 만든 새 창은 그대로 둬요.
 - 서브 모니터를 골랐는데 서브 모니터가 연결되어 있지 않으면, 아무것도 하지 않아요.

------------------------------------------------------------
■ 그만 쓰고 싶을 때
------------------------------------------------------------
 [2_제거하기.bat]을 더블클릭해요.

------------------------------------------------------------
■ 알아두면 좋은 단축키
------------------------------------------------------------
 창을 클릭한 뒤  [윈도우 키] + [Shift] + [← 또는 →]
 → 지금 창이 옆 모니터로 바로 넘어가요. (서브 모니터에 띄울 때 편해요)

------------------------------------------------------------
■ 잘 안 될 때
------------------------------------------------------------
 - 설치 창에 빨간 글씨가 나오면, 그 내용을 사진 찍어 보여 주세요.
 - 학교 컴퓨터는 보안 프로그램 때문에 막힐 수 있어요.
   이때는 정보 담당 선생님께 "PowerShell 스크립트 실행 허용"을 부탁해 보세요.
