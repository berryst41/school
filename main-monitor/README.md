# 🖥️ 메인 모니터로 열기

**한글·엑셀 같은 문서와 크롬·엣지·브레이브를, 프로그램마다 골라 둔 모니터(메인 / 서브)에서 열어 주는 윈도우 프로그램이에요.**
메인 모니터는 노트북, 서브 모니터는 전자칠판처럼 옆에 연결한 화면이에요. 다른 모니터로 옮겨 두고 껐던 창도, 다시 열면 골라 둔 모니터에서 열려요. 쓰는 동안에는 마음대로 옮겨도 돼요.

### [⬇️ main-monitor.zip 내려받기 (v1.4.1)](https://github.com/berryst41/school/raw/main/main-monitor/main-monitor.zip)

지금 버전: **v1.4.1** (2026-11-05) · 바뀐 점은 [아래 버전 기록](#버전-기록)에 있어요.

## 설치하는 방법

| 순서 | 할 일 |
|:---:|:---|
| 1️⃣ | 압축 파일을 마우스 오른쪽 클릭 → **모두 압축 풀기** |
| 2️⃣ | 풀린 폴더에서 **1_설치하기.bat** 을 더블클릭해요 |
| 3️⃣ | 파란 **Windows의 PC 보호** 창이 뜨면 **추가 정보** → **실행** |
| 4️⃣ | **열릴 위치 고르기** 창에서 프로그램마다 **메인 모니터 / 서브 모니터 / 사용 안 함** 을 고르고 **확인**<br>💡 **한쇼**와 **파워포인트**는 처음에 "사용 안 함"이에요. 그대로 두는 걸 추천해요 (발표 화면은 서브 모니터에 띄우는 경우가 많아서요) |
| 5️⃣ | "설치가 끝났어요!"가 나오면 엔터 키로 닫아요 |

화면에는 보이지 않고 뒤에서 조용히 작동하며, 컴퓨터를 켤 때마다 저절로 다시 켜져요.
나중에 열릴 위치를 바꾸고 싶으면 **3_프로그램고르기.bat** 을, 그만 쓰고 싶으면 **2_제거하기.bat** 을 더블클릭해요.

## 알아두면 좋아요

- 📄 문서: 한글 · 한셀 · 한쇼 · 한PDF · 엑셀 · 워드 · 파워포인트 · 아크로뱃(PDF)
- 🌐 브라우저: 크롬 · 엣지 · 브레이브 (처음 켤 때의 창만 옮기고, 탭을 끌어낸 창은 그대로 둬요)
- ✨ 한글·한셀·한쇼·한PDF·엑셀·워드·파워포인트·크롬·엣지·브레이브는 다른 모니터에 잠깐 떴다가 옮겨지는 일 없이 처음부터 고른 모니터에서 열려요. (크롬·엣지는 닫아도 뒤에서 계속 켜져 있으면 열린 뒤에 옮겨요. 자세한 설정은 사용방법.txt에 있어요)
- 🧰 따로 설치할 프로그램 없이 윈도우에 들어 있는 기능(PowerShell)만 써요.
- 🖥️ 노트북이 메인(주) 모니터인지 먼저 확인해요: 바탕화면 오른쪽 클릭 → **디스플레이 설정** → **이 디스플레이를 주 모니터로 만들기**
- ⌨️ 창을 옆 모니터로 바로 보내려면 **윈도우 키 + Shift + ← / →**
