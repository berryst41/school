# 📚 4원칙 학급 운영 자료실

**4원칙 학급 운영 자료를 휴대폰·PC에서 편하게 보는 곳이에요.**
아침 멘트, 수요일 중간놀이, 목요일 목힘, 금요일 인성놀이, 단단마인드, 수업놀이 추천을 한곳에서 봐요.

### [📚 자료실 열기](https://berryst41.github.io/school/class/)

> [!IMPORTANT]
> **허용 코드를 받은 사람만** 들어갈 수 있어요. 코드는 관리자가 한 사람씩 만들어 주고, 언제든 끌 수 있어요.

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

## 무엇을 볼 수 있나요?

| 화면 | 보이는 것 |
|:---|:---|
| ☀️ **오늘** | 맨 위에 **오늘의 아침 멘트**가 떠요(월~금). 그 아래 **이번 주 중간놀이 · 이번 주 목힘 · 이번 주 금요 인성교육 · 이번 주 수업놀이 추천**이 칸마다 따로 보여요. 요일과 상관없이 매일(주말에도) 보여서 미리 준비할 수 있어요. 이번 주 다른 자료와 작년 이맘때 자료도 같이 보여요. |
| 📂 **모아보기** | 연도(2025·2026)와 종류별로 모아 보고, 글자나 #태그로 찾아요. |
| ⚙️ **관리** (관리자만) | 허용 코드를 만들고, 끄고, 지워요. 구글 시트에서 자료를 바로 가져와요. |

자료를 누르면 전체 내용이 보여요. **📋 내용 복사**로 멘트를 그대로 복사할 수 있고, 영상·블로그 링크는 눌러서 바로 열 수 있어요.

## 휴대폰 홈 화면에 놓기

- **갤럭시(크롬):** 자료실을 열고 ⋮ → **홈 화면에 추가**를 눌러요.
- **아이폰(사파리):** 공유 단추 → **홈 화면에 추가**를 눌러요.

한 번 코드를 넣으면 그 기기에서는 다시 넣지 않아도 돼요. 다른 사람과 같이 쓰는 기기라면 **나가기**를 눌러 주세요.

## 자료는 어떻게 더하나요?

**지금처럼 구글 시트에 쓰기만 하면 돼요.** 자료실을 열 때 시트를 저절로 가져와요(10분에 한 번).

- 시트 모양은 지금 그대로 쓰면 돼요. 달마다 탭이 있고, 한 줄이 한 주차예요. 칸은 월~금 멘트, 중간 놀이, 금 놀이, 단단 마인드, 수업놀이 추천, 특별활동(목힘), 교사마인드, 주간 교육이에요.
- 바로 보고 싶으면 **⚙️ 관리 → 🔄 지금 가져오기**를 눌러요.
### 자료실에서 바로 넣기 (관리자)

오른쪽 아래 **＋ 자료 추가**를 누르고, 카톡 등에서 받은 멘트를 **#태그까지 통째로** 붙여 넣어요. 태그를 보고 알아서 나눠 줘요.

| 이런 태그가 있으면 | 이렇게 들어가요 |
|:---|:---|
| `#아침멘트` `#월밀` | 🌅 아침 멘트 (요일 태그가 없으면 오늘 요일) |
| `#목힘` `#수힘` `#특별활동` | 🫠 목힘, 목요일 |
| `#수업놀이1픽` | 🎲 수업놀이 |
| `#짧은놀이` `#중간놀이` `#수요일` | 🤸 중간놀이, 수요일 |
| `#교실놀이추천` `#금요일` | 💚 금요 인성교육, 금요일 |
| `#교사마인드` / `#주간교육` / `#단단마인드` | 그 종류로 |
| 그 밖의 태그 (예: `#미술`) | 지금까지 그 태그가 가장 많이 쓰인 종류로 |

- `#35주차`처럼 주차 태그가 있으면 그 주차로, 없으면 **이번 주**로 들어가요.
- 멘트 속 영상·블로그 주소는 저절로 링크 단추가 돼요.
- 넣기 전에 초록 칸에 "🪄 목힘 · 목요일 · 34주차로 넣을게요"처럼 미리 보여 줘요. 틀리면 아래 칸에서 바꾸면 돼요.

> [!NOTE]
> 자료실에서 바로 넣은 자료는 **구글 시트에는 들어가지 않아요.** 자료실 안에만 있어요. 시트에서 가져온 자료는 자료실에서 고칠 수 없고, **📝 시트에서 고치기** 단추로 시트를 열어 고쳐요.

> [!NOTE]
> 구글 시트는 **"링크가 있는 모든 사용자"** 보기 공유여야 자료실이 읽을 수 있어요. 시트 주소는 자료실 화면 어디에도 나오지 않아요(관리자만 볼 수 있어요).

## 허용 코드 나눠 주기

1. **⚙️ 관리**에서 이름을 쓰고 **만들기**를 눌러요.
2. 주소와 코드가 담긴 초대 글이 복사돼요. 카톡 등에 붙여 넣어 보내요.
3. 그만 보게 하려면 그 사람 옆의 **끄기**를 눌러요. 다음에 열 때부터 못 들어와요. 다시 **켜기**를 누르면 같은 코드로 다시 들어올 수 있어요.
