# 📮 자료 공유 사이트

**사진, 영상, 파일을 올리면 QR코드가 나와요.**
학생들은 휴대폰 카메라로 QR코드를 찍기만 하면 바로 받을 수 있어요.

### [📂 자료 공유 사이트 열기](https://berryst41.github.io/school/share/)

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

## 사용법

| 👩‍🏫 선생님 | 🧒 학생 |
|:---|:---|
| 반마다 **폴더**를 만들어요 | QR코드를 찍어 반 폴더에 들어가요 |
| 파일을 올리고 **QR코드**를 보여 줘요 | **이름**을 적고 들어가요 |
| 필요 없는 파일·폴더는 **삭제**해요 | 올라온 자료를 보고 내려받아요 |

## 용량 제한

> [!NOTE]
> - **파일 하나:** 50MB까지 올릴 수 있어요. 여러 개를 한 번에 골라 올려도 돼요.
> - **전체 합계:** 모든 반 폴더를 합쳐 **1GB**까지 저장돼요. 가득 차면 다 쓴 파일이나 폴더를 지워서 자리를 만들어 주세요.
>
> 50MB가 넘는 영상은 길이를 줄이거나 화질을 낮춰서 올려 주세요.
