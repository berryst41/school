### 🧾 품의 기안 도우미

<details>
<summary>👉 <b>눌러서 펼치기</b></summary>

> **장바구니를 읽어 품의 기안을 만들고, K-에듀파인에 복사·붙여넣기 없이 채워 주는 크롬 확장 프로그램**
> 쿠팡 · G마켓 · 11번가 · 아이스크림몰 장바구니는 AI 없이 무료로 읽어요.

👉 **[pumui-extension.zip 내려받기](https://github.com/berryst41/school/raw/main/pumui/pumui-extension.zip)**

<details>
<summary><b>🔧 설치하는 방법</b></summary>
<br>

| 순서 | 할 일 |
|:---:|:---|
| 1️⃣ | 압축 파일을 풀어 **extension** 폴더를 문서 폴더 같은 곳에 둬요 (지우지 마세요) |
| 2️⃣ | 크롬 주소창에 `chrome://extensions` 를 입력해요 |
| 3️⃣ | 오른쪽 위 **개발자 모드**를 켜요 |
| 4️⃣ | **압축해제된 확장 프로그램을 로드합니다**를 누르고 **extension** 폴더를 골라요 |
| 5️⃣ | 퍼즐 모양 아이콘에서 **품의 기안 도우미**를 📌 고정하고, 누르면 오른쪽에 도우미 창이 열려요 |

</details>

<details>
<summary><b>📝 쓰는 순서</b></summary>
<br>

| 순서 | 할 일 |
|:---:|:---|
| ① | 쇼핑몰 장바구니 화면에서 **이 페이지에서 장바구니 읽기** |
| ② | 사업 내용, 관련 문서번호 확인 (기안 품목 이름·관련은 안 적어도 돼요) |
| ③ | 에듀파인 품의 화면에서 칸을 한 번 누르고 **제목 넣기 / 본문 넣기 / 품목내역 넣기** |
| ④ | 내용을 확인하고 **저장·상신은 직접** 눌러요 |

> [!IMPORTANT]
> 도우미는 저장·상신·결재 버튼을 누르지 않고, 로그인·인증서 비밀번호도 묻지 않아요.

</details>

<details>
<summary><b>✨ 할 수 있는 일</b></summary>
<br>

- 💰 배송비를 포함한 금액으로 기안을 쓰고, 단가는 원래 단가로 적어요.
- ➕ **새로 채우기 / 뒤에 덧붙이기 / 새 품목만 덧붙이기** 중에서 골라 장바구니를 읽어요.
- 🧮 품목을 골라 **예산별로 나눠** 넣어요. 넣은 품목에는 `✓1차`처럼 표시돼요.
- ✂️ 한 품목의 수량을 **나눠서** 다른 예산에 넣을 수 있어요.
- ⬇️ 에듀파인 품목내역 줄이 모자라면 **행추가**를 대신 눌러요.
- 🏷️ 예산 이름을 비워 두면 에듀파인에서 고른 예산 이름을 읽어 적어요.
- 📊 품의 목록과 지난 품의를 **엑셀로 저장**하고, 지난 품의를 골라 지울 수 있어요.

</details>

</details>

<a id="main-monitor"></a>

### 🖥️ 메인 모니터로 열기

<details>
<summary>👉 <b>눌러서 펼치기</b></summary>

> **한글·엑셀 파일을 열면 늘 메인 모니터에서 열리게 해 주는 윈도우 프로그램**
> 전자칠판으로 옮겨 두고 껐던 창도, 다시 열면 메인 모니터에서 열려요. 쓰는 동안에는 마음대로 옮겨도 돼요.

👉 **[main-monitor.zip 내려받기](https://github.com/berryst41/school/raw/main/main-monitor/main-monitor.zip)**

<details>
<summary><b>🔧 설치하는 방법</b></summary>
<br>

| 순서 | 할 일 |
|:---:|:---|
| 1️⃣ | 압축 파일을 마우스 오른쪽 클릭 → **모두 압축 풀기** |
| 2️⃣ | 풀린 폴더에서 **1_설치하기.ps1** 을 마우스 오른쪽 클릭 → **PowerShell에서 실행** (윈도우 11은 **더 많은 옵션 표시** 안에 있어요) |
| 3️⃣ | 무언가를 물어보면 **Y** 를 입력하고 엔터 키를 눌러요 |
| 4️⃣ | "설치가 끝났어요!"가 나오면 엔터 키로 닫아요 |

작업 표시줄에 작게 줄어든 **메인 모니터로 열기** 창이 프로그램이에요. 닫지 말고 두면 컴퓨터를 켤 때마다 저절로 다시 켜져요.
그만 쓰고 싶으면 **2_제거하기.ps1** 을 같은 방법으로 실행하면 깨끗하게 지워져요.

</details>

<details>
<summary><b>✨ 알아두면 좋아요</b></summary>
<br>

- 📄 한글 · 한셀 · 한쇼 · 엑셀 · 워드 · 파워포인트 · 아크로뱃(PDF)에 적용돼요.
- 🧰 따로 설치할 프로그램 없이 윈도우에 들어 있는 기능(PowerShell)만 써요.
- 🖥️ 노트북이 주 모니터인지 먼저 확인해요: 바탕화면 오른쪽 클릭 → **디스플레이 설정** → **이 디스플레이를 주 모니터로 만들기**
- ⌨️ 창을 옆 모니터로 바로 보내려면 **윈도우 키 + Shift + ← / →**

</details>

</details>

### 📮 자료 공유 사이트

> 학생들은 휴대폰 카메라로 QR코드를 찍기만 하면 바로 받을 수 있어요.

👉 **https://berryst41.github.io/school/share/**

<details>
<summary><b>👩‍🏫 선생님 · 🧒 학생 사용법</b></summary>
<br>

| 👩‍🏫 선생님 | 🧒 학생 |
|:---|:---|
| 반마다 **폴더**를 만들어요 | QR코드를 찍어 반 폴더에 들어가요 |
| 파일을 올리고 **QR코드**를 보여 줘요 | **이름**을 적고 들어가요 |
| 필요 없는 파일·폴더는 **삭제**해요 | 올라온 자료를 보고 내려받아요 |

</details>

<details>
<summary><b>📦 용량 제한</b></summary>
<br>

> [!NOTE]
> - **파일 하나:** 50MB까지 올릴 수 있어요. 여러 개를 한 번에 골라 올려도 돼요.
> - **전체 합계:** 모든 반 폴더를 합쳐 **1GB**까지 저장돼요. 가득 차면 다 쓴 파일이나 폴더를 지워서 자리를 만들어 주세요.
>
> 50MB가 넘는 영상은 길이를 줄이거나 화질을 낮춰서 올려 주세요.

<details>
<summary><b>🕹️ 시작하는 방법</b></summary>
<br>

| 순서 | 할 일 |
|:---:|:---|
| 1️⃣ | **3명**이 각자 기기로 [게임 링크](https://berryst41.github.io/school/)에 들어가요 |
| 2️⃣ | 한 명이 **방 만들기**를 누르고, **방 번호 4자리**를 친구들에게 알려 줘요 |
| 3️⃣ | 친구들은 방 번호를 넣고 **들어가기**를 눌러요 |
| 4️⃣ | 모두 🎧 **이어폰**을 끼고 **음성 채팅 켜기**를 눌러요 (마이크 허용 창이 뜨면 **허용**) |
| 5️⃣ | **게임 시작!** 역할은 단계마다 랜덤으로 바뀌어요 |

> [!TIP]
> 혼자 미리 살펴보고 싶으면 **한 기기로 연습하기**를 눌러 보세요. 세 역할을 모두 볼 수 있어요.

</details>

<details>
<summary><b>💣 게임 규칙</b></summary>
<br>

| 걸린 시간 | 등급 | 점수 |
|:---:|:---:|:---:|
| ⏱️ 3분 안 | 🥇 **A** | 100점 |
| ⏱️ 5분 안 | 🥈 **B** | 70점 |
| ⏱️ 7분 안 | 🥉 **C** | 40점 |

- 모두 **20단계**예요.
- **7분**이 지나거나 실수를 **3번** 하면 💥 폭탄이 터지고, 라운드별 점수가 나오는 결과 화면이 떠요.
- 폭탄 종류: ✂️ 선 자르기 · 🔴 버튼 · 🔊 소리 · 💡 모스부호 · 🔣 문양
- 높은 단계에서는 폭탄이 **최대 3종류**까지 한꺼번에 나와요.
- **5단계부터** 🙈 원숭이는 안전장치가 줄어들지 않게 계속 펌프를 눌러야 해요.
