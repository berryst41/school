# 🎨 협동화 메이커

**A4 그림 한 장을 N장으로 쪼개 나눠 칠하고, 칠한 종이를 스캔하면 다시 한 장으로 합쳐 주는 도구예요.**
설치 없이 링크만 열면 되고, 그림 파일은 선생님 컴퓨터 밖으로 나가지 않아요.

### [🎨 협동화 메이커 열기](https://berryst41.github.io/school/coop-art/)

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

## 이렇게 써요

### ① 쪼개기 (인쇄용 PDF 만들기)

| 순서 | 할 일 |
|:---:|:---|
| 1 | A4 그림 파일(**PDF · JPG · PNG**)을 끌어다 놓거나 **[파일 고르기]** |
| 2 | 몇 장으로 나눌지 숫자(예: 21)를 넣으면 나눌 수 있는 모양(가로 3 × 세로 7 등)이 나와요. 👍 표시가 가장 크게 인쇄되는 모양이에요. |
| 3 | 미리보기로 나뉜 모양과 종이 한 장의 모습을 확인해요. |
| 4 | **[N장짜리 PDF 만들기]** → 내려받은 PDF를 **100%(실제 크기)** 로 인쇄해요. |

- 조각 하나하나가 A4 종이 한 장에 크게 들어가고, 둘레에 **검은 실선(재단선)** 이 둘러져 있어요. 아이들은 선 안쪽에 칠해요.
- 조각 모양에 따라 종이가 **가로 또는 세로**로 자동으로 정해져요.
- 종이 위쪽에는 `3 / 21 (가로 1번째 · 세로 3번째)` 처럼 번호가 적혀 있어요.
- PDF 그림이면 조각마다 선명하게 다시 그려서, 크게 늘려도 흐려지지 않아요.

### ② 합치기 (스캔 → 한 장)

| 순서 | 할 일 |
|:---:|:---|
| 1 | 처음에 나눈 모양(가로 × 세로 칸)을 확인해요. 쪼개기에서 쓴 값이 자동으로 들어가 있어요. |
| 2 | 칠한 종이를 스캔한 파일(JPG · PNG · **PDF**)을 모두 올려요. 파일 이름 순서(또는 PDF 쪽 순서)대로 1번 자리부터 놓여요. |
| 3 | 작은 그림들의 순서가 맞는지 보고, 틀리면 **◀ ▶** 단추나 **끌어다 놓기**로 바꿔요. 거꾸로 된 건 **⟳** 로 돌려요. |
| 4 | **[한 장으로 합치기]** → **JPG · PNG · A4 PDF**로 받아요. |

- 스캔한 종이에서 **검은 재단선 사각형을 찾아 선 안쪽만 잘라** 순서대로 이어 붙여요.
- 종이가 조금 **기울어져** 있어도 스스로 바로잡아요(약 ±4°).
- 선을 못 찾은 종이는 ⚠ 표시가 뜨고 종이 전체를 그대로 써요. 반듯하게 다시 스캔해 보세요.
- 검은 선이 조금 남아 보이면 **"선 안쪽으로 더 자르기"** 숫자를 키워요.

## 알아 두기

- **칠한 뒤 선을 지우거나 오리지 말고** 그대로 스캔해 주세요. 선이 있어야 정확히 잘라서 이어 붙여요.
- 선 바깥(종이 가장자리)에 검은 테두리나 큰 그림자가 있으면 인식이 어려워요. 스캐너로 반듯하게 스캔하는 게 제일 좋아요.
- 종이를 **90도 눕혀서** 스캔했을 때는 종이 모양을 보고 자동으로 돌리지만, 방향(시계/반시계)은 알 수 없어서 거꾸로 될 수 있어요. 그럴 땐 **⟳** 를 눌러 맞춰요.
- 도구는 브라우저 안에서만 움직여요. PDF 파일을 읽을 때만 인터넷에서 PDF 읽는 도구(pdf.js)를 한 번 불러와요. JPG·PNG는 인터넷 없이도 돼요.
- 합친 그림이 너무 크면(약 6천만 화소 이상) 자동으로 조금 줄여요.
