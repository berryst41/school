# 🎨 협동화 메이커

**A4 그림 한 장을 N장으로 쪼개 나눠 칠하고, 칠한 종이를 스캔하면 다시 한 장으로 합쳐 주는 도구예요.**
설치 없이 링크만 열면 되고, 그림 파일은 선생님 컴퓨터 밖으로 나가지 않아요.

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

> [!TIP]
> 처음이라면 **[🌈 예시 그림으로 해보기]** 로 쪼개 보고, ② 합치기에서 **[🧪 예시 스캔으로 해보기]** 를 눌러 보세요. 섞고 기울이고 거꾸로 돌린 스캔도 알아서 제자리에 붙는 걸 볼 수 있어요.

## 이렇게 써요

### ① 쪼개기 (인쇄용 PDF 만들기)

| 순서 | 할 일 |
|:---:|:---|
| 1 | A4 그림 파일(**PDF · JPG · PNG**)을 끌어다 놓거나 **[파일 고르기]** |
| 2 | **자주 쓰는 모양**(2×2, 3×3, 3×7 …)을 누르거나, 전체 장수(예: 21)를 넣고 나올 모양 단추를 눌러요. 👍는 그림이 가장 크게 인쇄되는 모양이에요. |
| 3 | 종이 방향(자동·세로·가로)과 넣을 것을 골라요. |
| 4 | 미리보기에서 **총 조각 수, 조각 1장 크기, 다 붙인 크기**와 **인쇄될 종이 목록**을 확인해요. 종이를 누르면 크게 보여요. |
| 5 | **[PDF 만들기]** → 내려받은 PDF를 **100%(실제 크기)** 로 인쇄해요. |

**조각 종이에는 이런 것들이 들어가요**
- 둘레의 **검은 실선(재단선)**: 이 선을 따라 자르고, 합칠 때 이 선을 기준으로 잘라요.
- **번호 코드**: 종이 아래쪽 작은 검은 점 줄이에요. 번호와 가로·세로 칸 수가 들어 있어서, 합칠 때 순서를 저절로 찾아요.
- **번호와 위치 지도**: 위쪽에 `3 / 21 (가로 1번째 · 세로 3번째)`, 오른쪽 위에 지금 조각 위치를 빨갛게 표시한 작은 지도가 있어요.
- **모서리 자르기 표시**: 선 모서리를 바깥으로 조금 더 길게 그려서 자를 때 도움이 돼요.
- **재단 여유**(선택): 그림을 선 바깥으로 조금 더 인쇄해서, 살짝 빗나가게 잘라도 흰 틈이 안 생겨요.
- **전체 배치도**(선택): 첫 장에 번호가 붙은 전체 그림과 크기 정보를 넣어요. 인쇄 장수가 1장 늘어요.

### ② 합치기 (스캔 → 한 장)

| 순서 | 할 일 |
|:---:|:---|
| 1 | 칠한 종이를 **자르기 전에** 스캔해요. 검은 선과 아래 점 줄이 다 보여야 해요. |
| 2 | 스캔 파일(JPG · PNG · **PDF**)을 모두 올려요. **순서가 섞여 있어도, 거꾸로 스캔해도 괜찮아요.** |
| 3 | 번호 코드를 읽어 **자리(순서)·방향·가로 세로 칸 수**를 저절로 맞춰요. 빠진 번호가 있으면 "빠진 자리: 3, 7번"이라고 알려 줘요. |
| 4 | **⚠ 확인 필요**가 뜬 조각은 그림을 눌러서 **네 모서리 점을 끌어 맞추고**, **자리 번호**를 고쳐요. |
| 5 | **[한 장으로 합치기]** → **JPG · PNG · A4 PDF**로 받아요. |

- 스캔에서 **검은 재단선 사각형을 찾아 선 안쪽만 잘라** 이어 붙여요. 종이가 조금 **기울어져** 있어도 스스로 바로잡아요(약 ±4°).
- 번호 코드가 없는 스캔(예전에 만든 종이 등)은 파일 이름 순서대로 놓여요. 틀리면 **◀ ▶** 단추나 **끌어다 놓기**로 바꾸고, 거꾸로 된 건 **⟳** 로 돌려요.
- 검은 선이 조금 남아 보이면 **"선 안쪽으로 더 자르기"** 숫자를 키워요.

## 알아 두기

- **칠한 뒤 선과 아래 점 줄을 지우거나 가리지 마세요.** 선이 있어야 정확히 자르고, 점 줄이 있어야 순서를 찾아요.
- 번호 코드를 넣으려면 종이 아래쪽 여백이 조금 필요해요(기본 12mm면 충분). 여백이 너무 좁으면 미리보기에 알림이 떠요.
- 스캐너로 반듯하게 스캔하는 게 제일 좋아요. 선 바깥에 검은 테두리나 큰 그림자가 있으면 인식이 어려워요.
- 도구는 브라우저 안에서만 움직여요. PDF 파일을 읽을 때만 인터넷에서 PDF 읽는 도구(pdf.js)를 한 번 불러와요. JPG·PNG는 인터넷 없이도 돼요.
- 합친 그림이 너무 크면(약 6천만 화소 이상) 자동으로 조금 줄여요.
