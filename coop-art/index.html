4. PDF 만들기

출력할 때는 프린터 설정에서 "실제 크기(100%)"로 인쇄해 주세요. 각 종이의 검은 실선이 잘라낼 선이에요. 아래쪽 번호 코드와 검은 선은 가리거나 지우지 말고 칠한 뒤 그대로 스캔하면, ② 합치기에서 자동으로 순서대로 이어 붙여 줘요.

1. 어떻게 나눴었나요?

가로 칸 × 세로 칸 = 21장 원래 그림은
번호 코드가 있는 종이는 스캔하면 가로·세로 칸 수가 저절로 채워져요.

2. 칠한 종이를 스캔한 파일 올리기

스캔한 JPG · PNG · PDF를 모두 끌어다 놓거나
번호 코드가 있으면 순서가 섞여 있어도, 거꾸로 스캔해도 괜찮아요. 코드가 없으면 파일 이름 순서(PDF는 쪽 순서)대로 놓여요.

3. 한 장으로 합치기

선 안쪽으로 더 자르기 % (검은 선이 조금 남으면 키워요)

스캐너로 종이를 반듯하게 스캔하면 가장 잘 돼요. 조금 기울어진 건 저절로 바로잡아요. ⚠ 확인 필요가 뜬 조각은 그림을 눌러서 네 모서리를 직접 맞추고 번호를 고칠 수 있어요.
