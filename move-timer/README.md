# ⏱️ 이동 타이머

**정해 둔 시간마다 "이동하세요!"를 목소리로 알려 주고, 저절로 다시 카운트를 시작해요.**
학생 수만큼 되풀이하고 끝나요. 갤러리 워크, 모둠 돌아가며 활동, 자리 돌며 쓰기 활동에 좋아요.

### [⏱️ 이동 타이머 열기](https://berryst41.github.io/school/move-timer/)

바뀐 점은 [아래 업데이트 기록](#업데이트-기록)에 있어요.

## 사용법

| 순서 | 할 일 |
|:---:|:---|
| 1 | **학생 수**를 넣어요 (− / + 단추도 돼요). 이 숫자만큼 카운트를 되풀이해요. |
| 2 | **한 번 카운트 시간**(분·초)과 **"이동하세요" 보여 줄 시간**(초)을 정해요. |
| 3 | **[▶ 시작]** → 카운트가 끝나면 화면이 주황색으로 바뀌고 여자 목소리로 "이동하세요!" → 정한 초가 지나면 다시 카운트 |
| 4 | 마지막 학생 차례가 끝나면 "끝!"이 나오고 "모두 끝났어요"라고 말해요. |

- **[⏸ 멈춤 / ▶ 이어서]** 잠깐 멈추기, **[⏭ 다음으로]** 지금 단계 건너뛰기, **[↺ 처음부터]** 처음으로
- **[⛶ 크게 보기]** 설정을 숨기고 시계를 크게 보여 줘요. TV·전자칠판에 띄울 때 좋아요.
- "이동하세요!" 대신 다른 말(예: "자리 바꿔요!")을 넣으면 그 말을 읽어 줘요.
- 설정은 그 컴퓨터에 저장돼서 다음에 열어도 그대로예요.

> [!TIP]
> 목소리는 컴퓨터·태블릿에 들어 있는 한국어 음성을 써요(윈도우·크롬·갤럭시·아이패드 대부분 있어요).
> 수업 전에 **[🔊 목소리 들어 보기]** 로 확인해 주세요. 한국어 음성이 없는 기기에서는 삑삑 소리로 알려 줘요.
